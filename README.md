# OverTheWire Bandit Writeups

A structured collection of OverTheWire Bandit writeups demonstrating Linux, networking, and cybersecurity skills.

## About

Bandit is a beginner-friendly wargame created by the OverTheWire team to teach Linux fundamentals, file handling, SSH, networking, and security concepts through practical challenges.

## Objectives

* Strengthen Linux command-line skills
* Learn cybersecurity fundamentals
* Practice CTF problem-solving techniques
* Document solutions and lessons learned
* Build a public cybersecurity portfolio

## Repository Structure

```text
levels/         Individual level writeups
screenshots/    Screenshots and terminal outputs
resources/      Notes and command references
```
